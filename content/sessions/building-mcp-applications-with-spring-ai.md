AI applications are evolving beyond simple text chats to interact with real tools, APIs, and external systems. This hands-on workshop teaches Java developers how to build end-to-end tool-enabled applications using **Spring AI** and the **Model Context Protocol (MCP)**.

Starting from a basic Spring Boot service, participants will:
- Connect local LLMs using Spring AI's `ChatClient`
- Implement a custom MCP server in Java and expose enterprise functions as discoverable MCP tools
- Build an MCP-enabled client that dynamically discovers and executes tools
- Utilize Ubuntu's `devpack-for-spring` for a preconfigured, zero-friction developer setup

No prior LLM development experience is required — just standard Java and Spring Boot knowledge!
