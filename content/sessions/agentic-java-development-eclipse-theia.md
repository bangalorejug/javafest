Developer tools are undergoing a major transformation with the integration of AI coding agents. Eclipse Theia AI provides an open, vendor-neutral framework for building AI-native development environments where developers remain in full control of their code, tools, and data.

In this hands-on workshop, participants will experience agentic Java development firsthand:
- Setting up and customizing Eclipse Theia AI for Java workflows
- Directing AI agents to navigate codebases, diagnose test failures, and refactor code iteratively
- Leveraging the power of automated feedback loops: letting the agent run `mvn test`, interpret test output, and fix errors step by step
- Exploring open protocols and model flexibility without vendor lock-in

By the end of this workshop, you'll understand how to harness open-source AI developer tooling to supercharge your daily Java engineering workflow.
