AI coding agents can inspect a repository, edit multiple files, run builds, diagnose failures, and iteratively produce working software. But what is actually happening behind the scenes when an agent writes code?

This lightning talk pulls back the curtain on AI coding agents:
- **The Perception-Action Loop:** How agents parse workspace context, project structure, and compiler feedback
- **Tool orchestration:** How file reading, AST analysis, terminal execution, and diff generation are structured as agent tools
- **Prompt engineering vs. System mechanics:** What the LLM actually decides versus what the agent harness controls
- **The future of Java development:** How developers can best collaborate with agents to write safer, cleaner code faster
